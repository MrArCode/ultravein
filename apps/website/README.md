# UltraVein Website

Company website of UltraVein and the future training platform: course catalog, registration, online payments, e-learning, and certificates.

## Structure

- [`client/`](client/README.md) – Angular front end. Public pages are prerendered to static HTML for fast loading and SEO.
- `server/` – ASP.NET Core API (planned): courses, registrations, payments, and certificate generation.
